# Security policy

Report vulnerabilities in the Quox Plugin SDK packages to **security@quox.ai**. Please do not open a public issue for a security problem.

Include the package and version, a description of the impact, and steps to reproduce. We aim to acknowledge reports within 3 working days.

Scope: the packages in this repository (`create-quox-plugin`, `quox-plugin-sdk`, `quox-plugin-vite`, `eslint-plugin-quox-plugin`). Vulnerabilities in the Quox host platform should be sent to the same address.
